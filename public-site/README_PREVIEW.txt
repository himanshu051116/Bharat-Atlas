Bharat Atlas v1.11 — Optimized Public Research Preview

This site is an interactive research and learning prototype, not a certified political map, legal boundary reference, or navigation product.

THE PUBLIC PACKAGE DOES NOT INCLUDE any operator-supplied Survey of India-derived national-claim outline, its original data, derived vectors, hashes, caches or alternate representations. No official 2026 Indian state, district or national political boundaries are certified here. Consult the Survey of India official publication for claims and legal boundaries. Generalized Natural Earth physical layers and selected historical world geographic features are included only as source-labelled context.

To view locally, extract all files and run the included START_PREVIEW_WINDOWS.bat or start an HTTP server in this directory: `python -m http.server 8000`; then open http://localhost:8000/ .

For web hosting (Vercel), deploy this folder directly with Framework Preset Other and no build command. Main entry is index.html; World Explorer is world.html. Do not deploy a private archive with restricted mapping data.

MapLibre/remote CDN may not be available offline, in which case the site uses a simplified SVG fallback. Actual hardware GPU, mobile and contemporary geographic completeness remain unverified.

This release preserves the v1.11 smoothing/performance work. Other licence notices in the package still apply to their respective third-party data. Source/asset integrity is documented in build-manifest.json.
