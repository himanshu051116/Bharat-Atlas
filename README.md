# Bharat Atlas v1.11 — release staging

This branch contains selected public-safe source pages and engineering notes recovered from the Bharat Atlas release package. **It is incomplete and is not deployable**: JavaScript/CSS bundles, GIS datasets, tiles and other production assets have not yet been uploaded.

Do not deploy this branch to Vercel. The main branch and currently hosted site have not been changed by this staging commit.

The full release is packaged separately as `Bharat_Atlas_v1_11_Optimized_Public_GitHub_Site.zip`; upload the complete contents before publishing. Restricted Survey of India claim outlines must not be uploaded publicly.
